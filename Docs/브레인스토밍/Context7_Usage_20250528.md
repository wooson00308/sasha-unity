## 논의 개요

컨텍스트7 도구를 효과적으로 사용하는 방법에 대해 심층적으로 논의하고, 그 결과를 문서화하기로 결정함.

## 주요 논의 내용 및 기본 활용 방안

*   **컨텍스트7 기능:** 라이브러리 검색(`resolve-library-id`) 및 최신 문서 조회(`get-library-docs`). 개발 시간 단축, 정보 정확성, 학습 곡선 감소에 기여 기대.
*   **한계점:** 검색 정확도 및 최신 정보 반영에 불확실성 존재.
*   **기본 사용법:** 명확한 검색어, 정확한 ID 확인, `topic` 파라미터 활용, 결과 교차 검증.

## '원리부터 생각하기' 모델 분석 결과

*   **근본 문제:** 개발자가 필요한 라이브러리 정보를 빠르고 정확하게 얻기 어렵다는 점.
*   **컨텍스트7 해결 방식:** 정형화된 최신 문서를 빠르게 제공.
*   **다른 해결 방식:** 웹 검색(정보 파편화/최신성 부족), 커뮤니티 질문(응답 시간/질문 명확성), 코드 예제 분석(맥락 파악 어려움).
*   **컨텍스트7 제약 원인:** 자연어 쿼리-ID 매칭의 한계, 학습 데이터 범위/깊이, 정보 업데이트 주기.
*   **효과적 사용법:** 정확한 입력, 다른 도구(web_search, grep_search)와 조합, 결과 신뢰성 검증 필수. 정보 탐색의 시작점 또는 보조 도구로 활용.

## 심층 활용을 위한 향후 어젠다

1.  컨텍스트7의 고급 기능 및 제약사항 심층 분석.
2.  다양한 개발 시나리오별(새 기술 학습, 에러 해결 등) 활용 전략 탐색.
3.  검색 결과의 신뢰성 평가 기준 및 코드 적용 시 유의사항 정리.
4.  컨텍스트7과 다른 도구(grep_search, web_search)의 연계 활용 방안 모색.
5.  실제 사용 경험 공유 및 개선점 도출.
